# What The Ship Remembers

Videojuego 2D de terror sci-fi hecho en Godot 4.7.2 (estable).

## Cómo abrirlo
Abrir Godot, "Importar" y elegir `what-the-ship-remembers/project.godot`.

## Estructura
- `what-the-ship-remembers/` — proyecto de Godot
  - `datos/` — JSON del juego (objetos, salas, guion de turnos, textos)
  - `escenas/` — escenas (.tscn): salas, personaje, interfaz
  - `scripts/` — código GDScript
  - `arte/` — sprites, tileset y sonido (greybox hasta el paso 11)

El diseño y la hoja de ruta del Alfa viven en el Project de Claude.
